❓ 小綸出題小幫手 使用說明

🚀 快速開始

  1. 選擇出題模式：「🤖 AI智慧搜尋」直接用課綱知識出題；「📂 上傳檔案/圖片」讓小綸讀你的教材出題
  2. 填年級/科目/版本/範圍（AI搜尋模式）或上傳檔案（上傳模式），設定題數/題型/難度/語言
  3. 按「🚀 小綸開始出題」，等待生成完成

🔑 關於 API Key

不填自己的Key：用小綸內建額度，每次出題間隔30秒冷卻。有自己的Google API Key：不受冷卻限制，用量算自己的（點畫面最上方進場頁的「我有自己的API Key」，或表單裡的小連結可以叫回填Key的欄位）。

📝 出題完成後可以做什麼

  • 編輯內容：直接點試卷上的文字修改，跟打字一樣
  • 🔁 重新出這題：只有某一題不滿意，不用整份重出
  • ⬇️ 下載：可選 Word / PDF / 純文字三種格式
  • 🖨️ 列印：直接印出或存成PDF
  • 📱 線上作答（開新分頁）：自己先開一個新分頁測試看看學生作答會看到什麼畫面、怎麼自動評分
  • 📤 分享題目(學生作答)：產生連結傳給學生，學生開了直接線上作答＋自動評分，看不到答案
  • 📤 分享答案(家長)：產生連結傳給家長，可查看題目與解析（唯讀）
  • 📜 出題紀錄：這台裝置留有最近20次出題紀錄，可以重新開啟
  • 🔗 複製目前設定連結：把年級/科目/範圍等設定分享給同事，對方開了會自動帶入表單
  • 💾 儲存設定條件：把目前的年級/科目/範圍等設定存在這台裝置，下次打開頁面自動帶入，手機上不用每次重填
  • 🗑️ 清除所有條件：把表單清空，也會刪掉已儲存的預設值

⚠️ 提醒

AI生成的題目請務必自行審核校對；分享連結30天後會過期；填空/簡答題的線上作答評分只是文字比對僅供參考，還是要老師/家長自行核對。
