❓ Luno 綸諾 使用說明

🚀 快速開始

  1. 選擇出題模式：「🤖 AI智慧出題」直接用課綱知識出題；「📂 上傳檔案/圖片」讓 Luno 讀你的教材出題
  2. 填年級/科目/版本/範圍（AI出題模式）或上傳檔案（上傳模式），設定題數/題型/難度/語言
  3. 按「🚀 Luno 開始出題」，等待生成完成

🔑 關於 API Key

不填自己的Key：用Luno 內建額度，每次出題間隔30秒冷卻。有自己的Google API Key：不受冷卻限制，用量算自己的（點畫面最上方進場頁的「我有自己的API Key」，或表單裡的小連結可以叫回填Key的欄位）。

📝 出題完成後可以做什麼

  • 編輯內容：直接點試卷上的文字修改，跟打字一樣
  • 🎲 換這題：只有某一題不滿意時用，其他題目和你改過的內容都不受影響（要整份重來才按上方的「重新出整份」）
  • ⬇️ 下載：可選 Word（.docx）或 PDF 兩種格式
  • 🖨️ 列印：請先按「⬇️ 下載 ▾ → PDF」下載成PDF檔，打開後用PDF閱讀器本身的列印功能印出，畫面才會乾淨、不會有瀏覽器多餘的日期/網址/頁碼
  • 直接線上測驗：先選身分再分流，三種身分都不用註冊帳號——學生直接開新分頁作答（自動評分）；家長貼上孩子傳來的監看連結就能看每題作答（或登入家長帳號一次管多個孩子）；老師直接開全班即時進度儀表板（連結自帶金鑰，不用密碼也不用登入，但別把這條網址轉給學生）。發出去的監看連結隨時可以按「⏹ 停止監看」作廢（限老師／家長／管理員，學生不能關掉自己被監看）
  • 📤 發送測驗：按一次就把四種發法一起產好——6 位數代碼（課堂投影，學生在首頁輸入就進得去）、學生作答連結（直接線上作答＋自動評分，看不到答案）、家長答案連結（可看題目與解析，唯讀）、老師即時進度儀表板（自己留著，不要轉給學生）
  • 學生線上作答：可選「⚡每題即時看結果」或「📋全部寫完再送出」，並可選填姓名/年級/班級/座號；送出評分後可再產生「結果連結」分享回給老師/家長核對
  • 📜 出題紀錄：這台裝置留有最近20次出題紀錄，可以重新開啟
  • 🔗 複製目前設定連結：把年級/科目/範圍等設定分享給同事，對方開了會自動帶入表單
  • 💾 儲存出題條件：把目前的年級/科目/範圍等設定存在這台裝置，下次打開頁面自動帶入，手機上不用每次重填
  • 🗑️ 清除所有條件：把表單清空，也會刪掉已儲存的預設值

👤 帳號登入（選用，不登入也能用全部出題/作答/分享功能）

進場頁可以先選「快速使用（不登入）」，或選學生/家長/老師/管理員其中一種身分，登入或註冊帳號後才進入下一步（是否使用自己的API Key）。登入後多的功能：

  • 老師：註冊時幫班級取名字（如「六年1班」，全站需唯一，這就是學生加入用的班級代碼）；出題後多「💾 存入班級歷史」（全班共用，最多50份）；即時進度儀表板可點學生卡片「🔍 查看詳情」看監考式畫面（每題實際選了什麼/寫了什麼，不只是進度%）
  • 學生：註冊時班級代碼選填，之後也能在「我的帳號」補填；用分享連結作答時若有登入，家長之後不用等你傳連結就能直接查到進度（作答開始畫面最上方會看到登入狀態）
  • 家長：登入後在「我的帳號」輸入孩子的帳號名稱連結（不需孩子同意），連結後可直接查即時進度＋監考式詳情；若孩子沒登入純用分享連結作答，仍可請孩子手動分享「即時進度連結」給你查看（僅進度%）
  • 管理員：只能登入，不開放自助註冊（帳號由既有管理員手動建立）；登入後右上角會出現「🛡️ 管理後台」，可查看全站所有帳號、搜尋、手動建立帳號、修改角色/重設密碼、刪除帳號（刪除老師會一併刪除其班級與歷史記錄）

⚠️ 提醒

AI生成的題目請務必自行審核校對；分享連結30天後會過期；填空/簡答題的線上作答評分只是文字比對僅供參考，還是要老師/家長自行核對；目前沒有自助重設密碼功能，忘記密碼請重新註冊或聯絡開發者。
